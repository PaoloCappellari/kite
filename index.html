Fonte: Open-Meteo (ECMWF, ICON, ICON-2I, AROME, GFS). "Accordo" = quota di modelli che danno vento utile nel settore giusto. Clicca uno spot per aprirlo su Windy. Direzione = media vettoriale pesata sulla velocita' (le ore di calma non la falsano); "incerta" se i modelli non concordano. Vela: 2.2 × peso / vento, con il vento alzato del 30% della differenza raffica-media (bora rafficata = vela piu' piccola). Nei campi Reach / Evo SLS metti le misure che hai.
Se questa scritta non sparisce, il file e' aperto in un'anteprima che non esegue JavaScript (WhatsApp, Drive, Gmail, File di iPhone): aprilo con Chrome o Safari ("Apri con...").
